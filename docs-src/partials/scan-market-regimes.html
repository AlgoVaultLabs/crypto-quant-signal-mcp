Returns every coin on a venue whose market regime matches your filter. Each row is the market-regime classifier’s output for the last closed bar — the same classifier get_market_regime uses. One call replaces polling the whole venue coin by coin, and you pay per returned row: coins that don’t match are free.

When to use which

Tool Use it for
get_market_regimeA live single-coin read, including cross-venue funding.
scan_market_regimesFind every coin in a regime, as of the last closed bar.
scan_trade_callsRanked BUY/SELL verdicts.

scan_trade_calls rows also carry a regime field, but it is the trade-call engine’s three-label regime, with no confidence. If your logic is built on get_market_regime, use this tool.

How it works

  • After each bar closes, the venue’s whole universe is classified once.
  • Every call reads that one snapshot, so pages never mix two bars. as_of is the bar close; computed_at is when the snapshot was computed.
  • Rows are sampled on Binance, Bybit, OKX and Bitget.
  • A venue or timeframe that can’t currently be served is refused with alternatives — never answered with stale rows.

Parameters

Name Type Description
minConfidencenumberKeep only rows at or above this confidence (0–100). Optional.
maxRegimeAgeBarsnumberKeep only coins whose regime began within this many bars (1–500). 1 means the regime changed on the last closed bar. Optional.
coinsstring[]Your watchlist, up to 200 symbols. Symbols the venue doesn’t list come back in not_found and are not billed. Optional.
rankBystringScreen only a lens universe instead of every coin. Every lens is listed below, with the short alias it answers to. Optional — omit it to screen every coin.
topNnumberLens universe size (1–1000). Defaults to 100 when rankBy is set; without rankBy it selects the top coins by open interest. Optional.
minLiquidityUsdnumberDrop coins below this USD liquidity floor — notional open interest, or 24h volume on venues that expose no bulk open interest. Optional.
limitnumberPage size (1–100). Default: 20
offsetnumberRows to skip, for paging within one snapshot. Default: 0

Ranking lenses

Every value rankBy accepts. Pass the lens or its alias — both resolve to the same universe. Omit rankBy to screen every coin. With any lens except oi, rows also carry the lens metric.

Lens Alias Selects

Filters, explained

  • regime — any of the listed regimes.
  • minConfidence — a floor on confidence.
  • maxRegimeAgeBars — “just entered”: 1 means the regime changed on the last closed bar. A regime’s start is known only from the first change observed after the screener began recording, so coins whose start isn’t known yet are excluded by this filter.
  • assetClass — all, crypto, tradfi, equity, commodity, index, fx or premarket. tradfi is every non-crypto class; rows whose class is UNKNOWN appear only under all.
  • coins — your watchlist in one call. not_found lists the symbols the venue doesn’t list; they are not billed.
  • rankBy + topN — screen only a lens universe. topN alone takes the top coins by open interest.
  • minLiquidityUsd — a floor on the universe.
  • sortBy — confidence, regime_age (newest change first, unknown starts last) or rank (needs rankBy).
  • limit + offset — paging.

Recipes

Every coin trending up, confidence 60 or higher

scan_market_regimes({ exchange: "BINANCE", timeframe: "1h", regime: ["TRENDING_UP"], minConfidence: 60, limit: 100 })

Just turned — the regime changed within the last three bars

scan_market_regimes({ exchange: "BINANCE", timeframe: "1h", regime: ["TRENDING_UP","TRENDING_DOWN"], maxRegimeAgeBars: 3, sortBy: "regime_age" })

TradFi perps in a trend

scan_market_regimes({ exchange: "BINANCE", timeframe: "4h", assetClass: "tradfi", regime: ["TRENDING_UP","TRENDING_DOWN"] })

Ranging among the most-traded coins

scan_market_regimes({ exchange: "BYBIT", timeframe: "4h", rankBy: "volume", topN: 50, regime: ["RANGING"], sortBy: "rank" })

Your watchlist in one call

scan_market_regimes({ exchange: "BINANCE", timeframe: "1h", coins: ["BTC","ETH","SOL","XAU","TSLA"] })

The next page of the first recipe

scan_market_regimes({ exchange: "BINANCE", timeframe: "1h", regime: ["TRENDING_UP"], minConfidence: 60, limit: 100, offset: 100 })

If as_of changed between pages, a new bar closed — restart from offset: 0.

The screen → deep-dive loop

  1. Screen once per bar close — one call returns every coin in the regimes you care about.
  2. Deep-dive the matches — call get_market_regime only on the matched coins, for the live read with cross-venue funding.
  3. Apply your own logic — size, filter or act on what is left.

You pay for the rows you get back, not for the coins you didn’t need.

Refusals

A refusal comes back as a tool error whose text is a JSON object carrying code, message and suggested_action. Every refusal is unbilled.

Code When, what it carries, and what to do
invalid_parameterAn unknown rankBy lens, or sortBy: "rank" without rankBy. Carries param and, for rankBy, valid_values. Pass a listed lens, or sort another way.
venue_not_sampledThe venue is outside the sampled set. Carries sampled_venues. Pass one of them, or call get_market_regime for a single coin on that venue.
timeframe_unservedThe venue can’t currently serve that timeframe. Carries served_timeframes_on_venue and venues_serving_timeframe. Switch to one of them.
snapshot_staleThe newest snapshot is older than its freshness bound, or none exists yet. Carries as_of. Retry after the next bar close, or call get_market_regime for a live single-coin read.
TIER_LIMIT_REACHEDYour call allowance is used up. See Errors & troubleshooting.

A screen charges one call per returned row, minimum one per successful call. Coins that don’t match, and refusals, are free. Available on every plan, over MCP or the HTTP endpoint above.
